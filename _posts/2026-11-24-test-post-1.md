Understanding how linear regression works is essential as a foundation before moving on to more complex machine learning algorithms. The basic concept is to find the best-fitting straight line that maps the relationship between an input variable ($x$) and a target variable ($y$).

![Linear Regression Graph Illustration](assets/img/posts/testimage.jpeg)

Mathematically, the hypothesis function for simple linear regression is formulated as follows:

$$y = mx + b$$

To implement this quickly, we can use the `numpy` library in Python.

```python
import numpy as np

# Sample data
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 5])

# Calculate slope (m) and intercept (b)
m, b = np.polyfit(x, y, 1)

print(f"Line equation: y = {m:.2f}x + {b:.2f}")
